# Краткая документация

Данный репозиторий содержит конфигурационный docker-compose файл для работы удаленного доступа. Используется открытый проект [RustDesk](https://github.com/rustdesk/rustdesk). Требования для корректной работы сервиса:
- Скопировать репозиторий на сервер в домашний каталог
- Скопировать данные RustDesk в директорию data (если директории нет - предварительно создать в корне проекта)
- Запустить проект `docker compose up -d`

Архивирование содержимого директории data реализовано в файле `archivarius.sh`. Скрипт создает сжатый архив в отдельной директории, а также удаляет файлы архивов старше 15 дней. Для автоматизации рекомендуется использовать утилиту [cron](https://wiki.archlinux.org/title/Cron). Пример настройки *cron*:
```
0 5 */3 * * $HOME/RustDesk/archivarius.sh &> /dev/null
```
